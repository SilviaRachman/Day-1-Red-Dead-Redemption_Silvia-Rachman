*1. Deskripsi Singkat Repository*

Repository atau repo adalah tempat penyimpanan proyek secara online di GitHub. Di dalamnya, kita bisa menyimpan berbagai file sekaligus melihat riwayat perubahan yang pernah dilakukan. Repository ini dibuat khusus untuk menyimpan dokumentasi kegiatan Workshop Day 1.

*2. Tujuan atau Kegunaan Repository*

Repository ini memiliki beberapa kegunaan, yaitu:

- Menyimpan file proyek: Semua file dan kode bisa dikumpulkan dalam satu tempat agar lebih rapi dan mudah ditemukan.
- Mencatat perubahan: Setiap perubahan pada file tersimpan, sehingga kita bisa melihat riwayatnya atau kembali ke versi sebelumnya.
- Memudahkan kolaborasi: Repository bisa dibagikan melalui link sehingga anggota tim maupun orang lain dapat mengakses dan bekerja sama dalam proyek.

#b. Sesi STUPEN, PBL & Magang (Moderator: Kak Hanif)

Sesi ini membahas program Studi Independen (STUPEN), Project Based Learning (PBL), dan magang. STUPEN merupakan salah satu bentuk kegiatan dalam program MBKM yang mulai berjalan sejak 2020. Tujuannya adalah memberikan pengalaman belajar di luar kampus agar mahasiswa lebih siap menghadapi dunia kerja.

Beberapa hal yang dibahas mengenai program ini:

- Kegiatan di luar kampus dapat dikonversi menjadi SKS.
- Pembelajaran lebih fleksibel dan disesuaikan dengan kebutuhan mahasiswa.
- Program dapat berlangsung selama dua semester dengan total 20 SKS.
- Salah satu program unggulannya adalah MSIB, yaitu kegiatan bersertifikat yang bekerja sama dengan mitra industri.

Delapan bentuk kegiatan MBKM:

1. Pertukaran pelajar.
2. Magang.
3. Asistensi mengajar.
4. Penelitian atau riset.
5. Proyek kemanusiaan.
6. Wirausaha.
7. Proyek independen.
8. KKN.

Rencana kegiatan per semester:

- Semester 5: Studi independen di industri.
- Semester 6: Presentasi hasil studi independen di kampus.
- Semester 7: Magang.

Alur pendaftaran: Memeriksa data PDDikti, membuat akun, memilih program, mengikuti pendaftaran dan seleksi, kemudian menjalankan program hingga proses konversi SKS.

Selain itu, dijelaskan juga tiga model pembelajaran yang akan digunakan:

- Project Based Learning: Pembelajaran melalui pembuatan karya atau proyek nyata, seperti aplikasi, produk, dan prototipe.
- Problem Based Learning: Pembelajaran yang berfokus pada pemecahan masalah. Mahasiswa mencari informasi dan menyusun solusi dengan dosen sebagai fasilitator.
- Case Based Learning: Pembelajaran menggunakan studi kasus, mulai dari mengidentifikasi masalah, menganalisis, mencari solusi, hingga mempresentasikannya.

Mahasiswa juga perlu mengembangkan tiga kompetensi utama, yaitu Knowledge, Attitude, dan Skill yang mencakup kemampuan teknis maupun nonteknis.

Untuk Program Studi Teknik Multimedia Digital (TMD), terdapat 55 mata kuliah dengan total 144 SKS. Program studi ini memiliki visi menjadi prodi bertaraf internasional di bidang game, animasi, dan multimedia interaktif.

#c. Workshop "Building with AI, Managing Change with GitHub"

Workshop ini dibawakan oleh Nugi Farhan dan membahas dua materi utama, yaitu Prompt Engineering serta manajemen perubahan menggunakan Git dan GitHub.

1. Prompt Engineering

Prompt Engineering merupakan cara menyusun instruksi atau perintah kepada AI agar hasil yang diberikan sesuai dengan kebutuhan. Ada empat unsur penting dalam membuat prompt yang baik:

- Role: Menentukan peran AI.
- Task: Menjelaskan tugas yang harus dilakukan.
- Context: Memberikan informasi atau latar belakang.
- Format: Menentukan bentuk hasil yang diinginkan.

Semakin jelas instruksi dan konteks yang diberikan, semakin sesuai pula hasil yang dihasilkan AI.

2. Manajemen Perubahan (Git & GitHub)

Pada materi ini, dijelaskan perbedaan antara Git dan GitHub:

- Git: Alat untuk mencatat dan mengelola perubahan file atau kode di komputer.
- GitHub: Platform online untuk menyimpan repository Git sekaligus memudahkan kolaborasi.

Alur kerja Git terdiri dari tiga bagian, yaitu Working Directory, Staging Area, dan Repository (folder ".git").

#d. Poin Penting dan Hal Baru yang Dipelajari

Dari materi workshop, ada beberapa hal penting yang bisa dipahami, di antaranya:

1. Prompt Engineering

Membuat prompt yang jelas dan spesifik dapat membantu AI memberikan hasil yang lebih sesuai, mengurangi kesalahan, dan memudahkan kita mengatur hasil yang diinginkan.

2. Perbedaan Git dan GitHub

Git digunakan untuk mengelola perubahan file secara lokal di komputer, sedangkan GitHub digunakan untuk menyimpan repository secara online dan bekerja sama dengan pengguna lain.

3. Perintah Dasar Git

Beberapa perintah Git yang diperkenalkan dalam workshop antara lain:

- "git init": Membuat repository baru.
- "git add .": Memasukkan perubahan file ke staging area.
- "git commit -m": Menyimpan perubahan ke repository.
- "git push": Mengirim perubahan ke GitHub.
- "git pull": Mengambil perubahan terbaru dari GitHub.

4. Menghubungkan Komputer dengan GitHub

Koneksi antara komputer dan GitHub dapat dilakukan menggunakan SSH Key. Dalam workshop ini diperkenalkan penggunaan SSH Key jenis Ed25519 yang perlu didaftarkan melalui SSH Agent dan akun GitHub agar koneksi dapat dilakukan dengan aman.
